# 测试数据包说明

## 用途

数据包用于将本地自动化测试平台的可恢复运行数据迁移到部署服务器。源码通过 Git 仓库发布；本数据包应通过受控的服务器文件传输通道单独上传，不能提交到 Git 仓库。

本次已生成的数据包：`/tmp/novatest-data-20260728.tar.gz`，大小 `4.2MB`。

SHA-256：`885402f321625aed5712f33c98fe13c62cd4f1e69accdeff4dd9c552b32b7bd2`

## 包含内容

- `data/novatest.db`：项目、用例、执行任务、运行记录和报告索引。
- `data/case-assets/`：Web UI 用例关联的参考图片。
- `data/evidence/`：报告引用的执行截图证据。

## 不包含内容

- `.env`、`deploy/test.env` 或任何模型、CMS、账号密钥配置。
- `midscene_run/`：本地原始 Midscene 调试运行目录，可按需重新生成。
- `.DS_Store` 等系统文件。

## 恢复步骤

1. 停止部署服务器上的平台进程。
2. 将数据包解压到项目根目录，保留 `data/` 目录层级。
3. 确认部署环境中的 `.env` 或受控环境变量已经配置，再启动服务。
4. 访问 `GET /api/health`，然后登录平台并抽查测试资产、执行中心和一份历史报告。

## 安全要求

数据包可能包含测试用例请求内容、截图和运行结果。上传目标必须是受控服务器目录，传输完成后应记录包名、校验值、上传时间和保管责任人。
