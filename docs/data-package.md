# 测试数据包说明

## 用途

数据包用于将本地自动化测试平台的可恢复运行数据迁移到部署服务器。源码通过 Git 仓库发布；本数据包应通过受控的服务器文件传输通道单独上传，不能提交到 Git 仓库。

## 包含内容

- `data/novatest.db`：项目、用例、执行任务、运行记录、报告索引和运行配置。性能测试的账号池、场景配置、运行与阶段采样也保存在此数据库中；账号池明文仅限受控服务器访问。
- `manifest.json`：数据库 SHA-256 校验值。
- `README.md`：数据库恢复和校验说明。

## 不包含内容

- `.env`、`deploy/test.env` 等本地环境文件。运行凭据以 SQLite 数据包中的运行配置为准，不应另外写入源码或 Git。
- `midscene_run/`：本地原始 Midscene 调试运行目录，可按需重新生成。
- k6 的临时账号输入文件、汇总 JSON 和任何 Token。性能执行器在任务结束后会清理这些临时文件。
- `.DS_Store` 等系统文件。

## 恢复步骤

1. 停止部署服务器上的平台进程。
2. 将数据包解压到项目根目录，保留 `data/` 目录层级；校验 `manifest.json` 中的 SHA-256 后再覆盖数据库。
3. 确认解压后的 `data/novatest.db` 可由平台进程读取，再启动服务；只有初始化全新数据库时才使用一次性受控环境变量引导配置。
4. 访问 `GET /api/health`，然后登录平台并抽查测试资产、执行中心和一份历史报告。

## 安全要求

数据包包含运行凭据、测试用例请求内容、截图和运行结果。上传目标必须是受控服务器目录，传输过程和服务器存储均应受访问控制保护；传输完成后应记录包名、校验值、上传时间和保管责任人。源码仓库不得包含该数据库或任何运行凭据。
