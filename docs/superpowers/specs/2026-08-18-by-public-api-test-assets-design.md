# BY Web/H5 公共接口自动化资产设计

## 背景

`web-h5-api-reference.md` 定义 BY 的公开 Web/H5 接口，统一使用 `/c-api/v1` 前缀和 `{ code, msg, data }` 响应信封。`admin-api-reference.md` 定义管理后台接口，要求 JWT、可选 TOTP 和角色授权。当前未提供后台测试凭据，因此本期只将无需凭据且可真实执行的 Web/H5 接口接入平台。

## 目标

- 创建独立的“BY项目”，不影响现有项目和历史报告。
- 将文档定义的 Web/H5 公共接口转为可重复执行的正向、反向与边界自动化用例。
- 运行器同时验证 HTTP 状态码和 JSON 信封 `code`，在报告中保存脱敏请求与响应证据。
- 使用正常浏览器 User-Agent，满足接口的反爬请求约束。
- 将会创建举报记录的接口标记为变更型，默认不执行。

## 方案

新增 `by` API 协议与独立运行器。运行器只允许相对的 `/c-api/v1/...` 路径，基于用例的 `baseUrl` 构建同源请求，并对 GET 参数与 JSON 请求体分别编码。它接受预期 HTTP 状态码、预期业务码与 JSONPath 字段断言；当任一约束不符时，将脱敏后的请求和响应写入步骤证据后失败。

本期使用文档给出的测试 H5 地址作为 BY 项目的公共接口基地址。该地址不包含账号、密钥、令牌或加密材料。

## 用例覆盖

### P0 只读冒烟

- 会员列表、地区、站点信息、落地页、回家的路、客服和友情链接的成功响应与基本数据结构。
- 文章列表、公告列表，以及从列表项提取文章 ID 后查询详情的链路。
- 会员列表提取 `pubId` 后查询会员详情的链路，验证公开 ID 的使用方式。

### P1 参数、状态和数据契约

- 会员分页下界/上界回退、地区/身高/年龄/费用等组合筛选、下架状态不泄露。
- 会员详情的非法 ID、已下架或不存在记录的 `40400` 响应。
- 文章和公告分页、分类、非法详情 ID、未发布文章的 `40400` 响应。
- 图片 Token 非法或过期的 `40300` 响应，不读取或保存加密图片内容。
- 配置接口的链接、启用状态和 App 下载开关等字段契约。

### P2 受控写操作

- 举报接口的必填字段、超长字段、无效会员反例。
- 成功举报用例仅在批量或单条执行显式传入 `allowMutations` 时运行，使用运行时选取的上架 `pubId` 和可追踪的测试说明；不将举报数据写入固定种子。

## 安全与错误处理

- 不将登录凭据、JWT、TOTP、图片 Token、加密图片内容或敏感联系方式写入种子、SQLite、报告或 Git。
- 仅接受同源 `/c-api/v1` 路径，拒绝绝对 URL 和路径穿越。
- 仅记录 JSON 响应摘要；包含 `token`、`authorization`、`password`、`secret` 或 `contact` 的字段统一脱敏。
- 单条数据不足时，使用平台现有“前置数据不足”语义跳过依赖详情的用例，不把环境数据为空误判为接口故障。

## 管理后台范围

管理后台接口已完成覆盖分析但不在本期写入可执行资产：它要求测试账号、密码和可能的 TOTP 密钥，且包含账号、RBAC、支付、Telegram、发布、推送及删除等高风险操作。收到独立测试凭据后，再接入管理后台登录、授权隔离、只读查询与显式授权的受控写操作；删除、支付回调和外部 Telegram 连接保持排除。

## 验证

- 新增协议校验、请求编码、业务码失败、脱敏和同源限制的单元测试。
- 新增种子用例测试，验证项目归属、只读/变更型分层、唯一稳定 ID 和幂等写入。
- 新增组合执行器路由测试。
- 运行完整测试套件，并用实际测试地址执行 P0 只读用例，报告实际结果。
