# 测试资产 CRUD 与工作台分离设计

## 目标

将测试用例 CRUD 流程从工作台移至独立的测试资产模块。工作台仅负责执行、批次、运行报告和质量数据展示；资产模块负责用例查询、创建、编辑、删除和批量执行。

## 范围

- 使用现有静态页面和浏览器原生 hash 路由，不引入前端框架。
- 支持 Web UI 用例的创建、查询、更新和删除。
- 保持现有 Midscene 执行、串行批量执行和报告页面功能。
- 删除用例定义后保留既有运行记录、批次历史和报告。
- 不增加用户权限、用例版本、标签、批量删除或 API 测试资产。

## 路由与页面

| Hash 路由 | 责任 |
|---|---|
| `#/dashboard` | 执行状态、最近运行、批次历史、质量指标和报告入口 |
| `#/assets` | 用例表格、名称搜索、新建、编辑、删除、选择与批量执行 |
| `#/assets/new` | 新建 Web UI 用例的自然语言步骤编辑器 |
| `#/assets/:id` | 编辑既有用例的自然语言步骤编辑器 |

侧边栏的“工作台”和“测试资产”使用对应 hash。刷新页面时由 hash 决定当前视图。工作台不包含用例名称输入、步骤编辑器、保存草稿、新建用例或删除命令；顶部只保留“进入测试资产”入口。资产页承担原有用例选择和批量执行界面。

## 后端接口

| 方法 | 路径 | 行为 |
|---|---|---|
| `POST` | `/api/cases` | 创建校验后的 Web UI 用例，返回 `201` |
| `GET` | `/api/cases?q=` | 返回未删除用例；`q` 按名称不区分大小写过滤 |
| `GET` | `/api/cases/:id` | 返回一个可编辑的未删除用例，未知或已删除返回 `404` |
| `PUT` | `/api/cases/:id` | 以完整请求体替换用例元数据和步骤，返回更新后的用例 |
| `DELETE` | `/api/cases/:id` | 删除定义并返回 `204`；未知或已删除返回 `404` |

`POST /api/cases/:id/runs` 与 `POST /api/batches` 只允许活动用例。既有 API 的用例列表仍返回活动用例；批次和报告接口继续读取历史运行。

## SQLite 模型迁移

当前 `test_runs.case_id` 对 `test_cases` 有非空外键。为了物理删除用例定义并保留历史，启动时执行一次 schema 迁移：

1. 在 `test_runs` 新表中增加 `case_name TEXT NOT NULL`，移除 `case_id` 到 `test_cases` 的外键约束；同时重建 `batch_cases`，移除 `case_id` 到 `test_cases` 的外键约束。
2. 从旧 `test_runs` 复制所有记录，`case_name` 取关联 `test_cases.name`；找不到定义的旧记录使用 `已删除用例`。
3. 删除旧表、将新表改名为 `test_runs` 与 `batch_cases`，恢复 `run_steps` 对运行记录的外键约束和既有 `batch_id`、`batch_position` 数据。
4. 使用 `PRAGMA user_version` 标识该迁移已完成，避免重复执行。

删除用例时删除 `test_cases` 与其 `test_steps`；`test_runs.case_id` 与 `batch_cases.case_id` 仅保留历史 ID，不再受外键约束。新建运行时将当前用例名称写入 `test_runs.case_name`。运行对象新增 `caseName`，但保留 `caseId` 保持现有调用兼容。

## 报告和批次历史

报告渲染改为优先使用 `run.caseName`，不再依赖 `store.getCase(run.caseId)`。步骤结果、变量、日志和截图均由运行记录读取。

批次详情返回的每个运行记录含 `caseName`。资产定义删除后，批次历史仍显示运行名称、状态和报告链接；当前资产列表中没有该记录，也不能重新运行。

## 前端交互

资产列表是表格布局，显示名称、目标、视口、步骤数量、更新时间和操作菜单。搜索仅匹配名称。点击行或“编辑”进入 `#/assets/:id`；“新建用例”进入 `#/assets/new`。编辑页复用现有步骤编排控件，保存后返回资产列表。

删除命令打开确认对话框，明确提示“删除后不能再次执行，历史报告会保留”。确认期间禁用按钮，成功后回到资产列表并刷新；失败时展示 API 错误。批量选择和串行批量执行只在 `#/assets` 可用。

## 测试验收

1. API 可创建、按名称查询、读取、更新和删除活动用例。
2. 删除后的用例不在列表中，读取、执行和加入新批次均返回 `404` 或 `400`。
3. 删除前创建的运行和报告仍可读取，报告标题使用运行快照名称。
4. SQLite schema 迁移保留既有运行、步骤结果、批次和批次运行顺序。
5. 工作台不渲染用例编辑器或 CRUD 控件，资产页渲染搜索、新建、编辑、删除和批量执行控件。
6. 桌面及 `390x844` H5 视口可在工作台与资产页间导航，创建、编辑、删除和报告入口可用。
