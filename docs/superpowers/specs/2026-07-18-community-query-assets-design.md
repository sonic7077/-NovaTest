# 方舟社区查询资产与工具栏设计

## 目标

优化方舟社区发帖项目的测试资产筛选体验，移除面向用户的 CMS 与解密实现用语，并新增三条可独立执行的只读查询接口用例。

## 工具栏与搜索

- 资产工具栏采用三列布局：用例名称搜索框占用剩余宽度，类型下拉固定约 180px，刷新按钮固定宽度。
- 搜索框保留“搜索用例名称”提示，在输入时调用现有 `GET /api/cases?q=...` 接口，并由服务端按名称进行不区分大小写的模糊匹配。
- 类型筛选仍在当前项目资产范围内生效；切换类型时清除当前批量选择，避免跨类型批量执行。
- 窄屏幕下工具栏纵向排列，搜索、下拉与刷新控件均保持可点击尺寸。

## 文案

- 现有用例重命名为“社区发布配置查询”。
- 接口编辑页和执行状态移除“CMS 加密”等实现描述，统一使用“接口测试”。
- 报告 API 证据标题由“解密后响应”改为“响应内容”。
- 加密、自动响应解密、会话复用与敏感字段掩码仍保留在服务端实现中，不向资产用户展示。

## 查询用例

以下用例属于“方舟社区发帖”项目，均为 API 目标、一个只读 `POST` 步骤、预期业务状态 `1`，不显式保存登录步骤：

| 用例名称 | Action | Payload |
| --- | --- | --- |
| 帖子列表查询 | `list_post` | `{ "status": 10 }` |
| 评论列表查询 | `list_post_comments` | `{ "status": 0 }` |
| 用户资料修改记录查询 | `list_member_update_log` | `{ "status": 10 }` |

- 用例按名称幂等写入，重复实施时更新现有定义，不创建重复资产。
- 真实调试仅读取运行时 CMS 配置；每次单条运行由执行器自动认证，批量运行复用批次内会话。
- 运行报告仅展示已脱敏的响应内容；不得保存或输出 token、密码、密钥、IV、签名或传输密文。

## 验收标准

- 桌面端下拉筛选不再占据搜索框宽度，名称搜索可见且能实时筛选当前项目用例。
- 资产列表、接口编辑状态和新生成报告不出现“CMS”或“解密”字样。
- 目标项目含配置查询和三条新增只读查询用例，名称清晰且无重复。
- 三条新增查询用例均可执行并生成已脱敏报告；失败时仅记录安全错误。
