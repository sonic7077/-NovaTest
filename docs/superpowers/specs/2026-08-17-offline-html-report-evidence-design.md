# 离线 HTML 测试报告图片设计

## 背景

单条和批量报告的下载文件使用 `/api/runs/:id/evidence/:fileName` 与 `/api/cases/:id/assets/:fileName` 相对地址展示图片。该文件以 `file://` 打开时没有平台 HTTP 服务作为地址根目录，导致执行截图和视觉校验参考图无法加载。

## 目标

- 下载后的单条与批量 HTML 报告可在本地离线查看其执行截图。
- 包含视觉校验的报告同时展示参考图与执行截图。
- 平台内报告维持现有受控 HTTP 图片地址和访问白名单。
- 不在下载报告中增加令牌、账号、加密参数或未登记的文件内容。

## 方案选择

下载接口采用独立 HTML 方案。服务端仅对该报告实际引用且已登记的图片读取文件，将其编码为 `data:image/...;base64,...` 并传给报告渲染器。报告中的图片链接与 `src` 均使用该内嵌值，因此脱离平台服务也可加载。

未选择 ZIP 附件方案，因为用户需要直接双击打开 HTML。未选择绝对服务地址方案，因为服务停止、地址变化或报告转发后仍会失效。

## 架构与数据流

1. 在线查看路由继续调用现有 `renderReport` / `renderBatchReport`，不提供嵌入图片映射。
2. 下载路由根据运行记录收集截图文件名，并只从对应运行的证据目录读取已登记文件。
3. 下载路由根据视觉校验记录收集参考图，仅通过现有案例资产边界解析合法路径。
4. 文件读取服务限制 MIME 类型为 PNG、JPEG 或 WebP；不存在、格式不支持或读取失败的图片不嵌入。
5. 渲染器优先使用传入的嵌入图片映射，映射缺失时回退现有在线 URL；因此报告正文、状态锚点与 API 脱敏输出保持不变。

## 失败处理

- 单张图片缺失或不可读时，报告保留步骤和错误信息，不中断整份报告导出。
- 图片只能来自运行中登记的截图或关联用例的视觉参考图，路径穿越和未登记文件不可读取。
- HTML 内嵌的图片数据不进入 SQLite、运行变量或执行日志。

## 验证

- 添加单条下载报告回归测试，断言 HTML 含内嵌 PNG 数据且不含平台证据 URL。
- 添加批量下载报告回归测试，断言每个运行的截图可独立内嵌。
- 添加视觉校验回归测试，断言参考图和执行图均离线可用。
- 确认在线报告仍输出受控 HTTP 图片地址。
- 运行完整自动化测试与构建前检查。

## 范围外

- 不改变截图采集、报告样式、API 报告内容或数据库结构。
- 不将图片导出为 ZIP，不新增永久副本，也不修改历史报告数据。
